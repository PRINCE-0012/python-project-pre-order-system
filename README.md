# Smart Campus Food Pre-Order Website

A Flask website version of the command-line Smart Campus Food Pre-Order System.

## Features
- Food menu with quantities
- Student name and roll number
- Automatic subtotal and 10% discount for subtotal >= ₹300
- Order token and receipt
- Order status lookup
- Order cancellation
- SQLite database, so orders remain saved between app restarts

## Run on macOS

1. Install Python 3 if it is not already installed.
2. Open Terminal and move into this folder. Example:

   ```bash
   cd ~/Downloads/smart_campus_food_website
   ```

   Use the actual location where you extracted this folder.

3. Create and activate a virtual environment:

   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```

4. Install the dependency:

   ```bash
   pip install -r requirements.txt
   ```

5. Start the website:

   ```bash
   python app.py
   ```

6. Open this address in your browser:

   http://127.0.0.1:5000

Keep Terminal open while using the website. Press Control+C in Terminal to stop it.

## Notes
- The first order token is generated by SQLite and may start at 1. Existing CLI token numbers are not imported automatically.
- This is a local demo. It is not a public production deployment, and it does not process online payments.
- The estimated pickup time is a simple estimate based on the active queue position (5 minutes per position).
- For a real multi-user/public deployment, use a production server, configure a secret key, add appropriate access controls, and review privacy/security.
